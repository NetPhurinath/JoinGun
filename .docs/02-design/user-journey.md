# JoinGun — เข้าร่วมกิจกรรมจากฟีด

ผู้ใช้: นักศึกษาที่เข้าสู่ระบบและยืนยันอีเมลสถานศึกษา (.ac.th) แล้ว โดยมีกิจกรรมที่เปิดรับและยังมีที่ว่างในฟีด ขอบเขตนี้เริ่มหลังการสมัครสมาชิก และจบเมื่อเข้าร่วมสำเร็จ

1. ฉันเปิด JoinGun บนมือถือ เห็นหน้า **“กิจกรรม”** เป็นการ์ดเรียงคอลัมน์เดียว พร้อมชื่อกิจกรรม วันเวลา สถานที่ และจำนวนผู้เข้าร่วม จึงเลื่อนดูรายการได้ด้วยมือเดียว
2. ฉันแตะ **“ตัวกรอง”** เลือกหมวดกิจกรรมและวันที่ว่าง แล้วแตะ **“แสดงกิจกรรม”** เห็นฟีดที่ตรงกับตัวเลือก และแตะ **“ดูรายละเอียด”** บนการ์ดที่สนใจ
3. ฉันเห็นหน้า **“รายละเอียดกิจกรรม”** พร้อมข้อมูลผู้จัด ป้าย “ยืนยันอีเมลสถานศึกษาแล้ว” วันเวลา ที่ว่าง และแผนที่จุดนัดหมาย เมื่อตัดสินใจว่าเวลาและสถานที่เหมาะสม ฉันแตะ **“เข้าร่วมกิจกรรม”** ที่แถบด้านล่าง
4. ฉันเห็นแผง **“ยืนยันการเข้าร่วม”** สรุปกิจกรรมและแจ้งวัตถุประสงค์การเก็บประวัติการเข้าร่วม ฉันอ่านและเลือกช่อง **“ยินยอมให้เก็บประวัติการเข้าร่วมเพื่อจัดการกิจกรรมของฉัน”** ที่ยังไม่ถูกเลือก แล้วแตะ **“ยืนยันเข้าร่วม”** โดยไม่ต้องเปิด GPS ส่วนตัว
5. ฉันเห็นข้อความ **“เข้าร่วมสำเร็จ”** พร้อมชื่อกิจกรรม วันเวลา และจุดนัดหมาย แล้วแตะ **“ดูรายละเอียดกิจกรรม”** กลับไปเห็นสถานะ **“เข้าร่วมแล้ว”** และจำนวนผู้เข้าร่วมที่อัปเดต จึงทราบว่านัดหมายถูกบันทึกแล้ว

อ้างอิง: [Requirement Spec](../01-requirements/01-spec/20260908-01-joingun.md) F1, F3, LR1 และ Scope workflow 4; [Product Backlog](../01-requirements/backlog.md) 2.2–2.4, 3.1, 7.1–7.2, 8.1; [กฎโครงการ](../../rule.md) เรื่องความยินยอมและความปลอดภัย

ข้อกำหนดการออกแบบสำหรับ flow นี้: เข้าร่วมได้ทันทีเมื่อมีที่ว่าง เพราะ story 2.4 ไม่ระบุขั้นตอนรอผู้จัดอนุมัติ; แสดงคำขอความยินยอมเมื่อยังไม่มีความยินยอมที่ใช้ได้ ส่วนผู้ที่ให้ไว้แล้วเห็นสรุปและปุ่มยืนยันโดยไม่ต้องให้ซ้ำ
