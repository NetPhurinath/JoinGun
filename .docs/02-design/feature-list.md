- **CORE — เข้าร่วมกิจกรรมจากฟีด (สร้างก่อน):** ดูฟีด ค้นหา/กรอง เปิดรายละเอียด และเข้าร่วมกิจกรรมที่สนใจ เพื่อหาเพื่อนร่วมกิจกรรมในมหาวิทยาลัย (F3, Scope workflow 4; Backlog 2.2–2.4, 7.1–7.2)
- **บัญชีผู้ใช้:** สมัครและยืนยันอีเมลสถานศึกษาที่ลงท้ายด้วย .ac.th จัดการโปรไฟล์และบัญชี เป็นพื้นฐานก่อนใช้งาน core feature (F1; Backlog 1.1–1.3, 7.3)
- **จัดกิจกรรมและจุดนัดหมาย:** โพสต์รายละเอียด วันเวลา จำนวนคน และปักหมุดแผนที่; ค้นหาสถานที่และนำทางเป็นส่วนเสริม (F2; Backlog 2.1, 3.1–3.2)
- **การแจ้งเตือน:** เตือนก่อนเริ่มกิจกรรมและตั้งค่าการรับแจ้งเตือน พัฒนาต่อจาก core workflow (F4: Should; Backlog 4.1–4.2)
- **ความเป็นส่วนตัวและข้อมูล:** ขอความยินยอมแยกตามวัตถุประสงค์ ปกป้องข้อมูลและบันทึกการใช้งานตั้งแต่แรก; ตั้งค่าผู้เห็นประวัติเป็นส่วนเสริม (F5, LR1–LR5; Backlog 8.1–8.2)
- **สังคมและความปลอดภัย:** บล็อก/รายงานผู้ใช้ และเพิ่ม/จัดการเพื่อน โดยระบบเพื่อนเป็นงานต่อยอด (Backlog 5.1–5.3)
- **คำแนะนำเฉพาะบุคคล:** AI แนะนำกิจกรรมและปรับฟีดตามความสนใจเป็นงานภายหลัง โดยยึด F6: Could แม้ Backlog 6.1–6.3 ให้บางรายการเป็น High; แชตส่วนตัวและกลุ่มถาวรอยู่นอกเฟสแรก (F7, Scope)
