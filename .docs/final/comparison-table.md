# Before / after comparison

Evidence labels: **TEAM** means internal technical measurement; **PROXY** means external respondents/students evaluated a local build outside moderated deployed UAT. Active task effort was measured across Scenario Set A (Usual Way / Chat kit) vs. Set B (JoinGun) with 16 proxy respondents (`n = 16`, `U01–U16` in `JoinGun - Testing.xlsx`). No moderated REAL deployed test with live students has been run.

### Interpretation limits

The proxy results reflect post-demo evaluation and task walk-through with 16 proxy respondents (`PX01–PX16`), not a multi-week student field trial on a live deployed service. Real-user UAT on a deployed HTTPS service remains incomplete with zero evidence gathered to date. See the [test plan](../03-testing/test-plan.md) and [testing summary](../03-testing/no-real-user-test.md) for method details and targets.
