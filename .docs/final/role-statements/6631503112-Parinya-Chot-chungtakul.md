# Parinya Chotchungtakul — QA/Test

## What I owned

I was responsible for testing the JoinGun system and conducting user evaluation. My QA work included checking implemented flows against the test plan, recording defects, and validating system behavior. On the technical side, the repository includes the [test plan](../../03-testing/test-plan.md) and [browser end-to-end tests](../../../tests/e2e/core-journey.spec.js), reporting 47/47 API and database integration checks and 6/6 browser checks passing as of 2026-10-28.

For user testing, my verified work centers on the **PROXY testing**, which has full documented evidence in the repository. I conducted this evaluation with 16 external proxy respondents (`PX01–PX16`), measuring core workflow tasks (Scenario Set B), usability (SUS mean 57.66), technology acceptance (TAM: PU 4.08, PEOU 3.97, BI 3.81, Perceived Safety 3.66), and paired overall satisfaction (`n = 10`). This PROXY testing is completed, and its data has been entered into the project's primary UAT document, [JoinGun - Testing.xlsx](../../03-testing/JoinGun%20-%20Testing.xlsx) (along with the raw survey workbook [JoinGun — แบบสอบถาม SUS และ TAM (Responses).xlsx](../../03-testing/JoinGun%20%E2%80%94%20%E0%B9%81%E0%B8%9A%E0%B8%9A%E0%B8%AA%E0%B8%AD%E0%B8%9A%E0%B8%96%E0%B8%B2%E0%B8%A1%20SUS%20%E0%B9%81%E0%B8%A5%E0%B8%B0%20TAM%20%28Responses%29.xlsx) and the [testing summary](../../03-testing/no-real-user-test.md)). Note that the separate template file `uat-record.xlsx` holds no recorded data; all empirical UAT records reside in `JoinGun - Testing.xlsx`.

In contrast, moderated sessions with real users (`REAL` UAT) on a deployed HTTPS environment have not yet been completed and currently have no recorded evidence. If any facilitated testing with real users is conducted, the session dates, testing methodology, participant count and anonymized participant codes/IDs, and empirical results must first be recorded as evidence before any claim or reference to that testing can be made. My role statement therefore explicitly refers to the completed PROXY testing as the substantiated user evidence to date.
